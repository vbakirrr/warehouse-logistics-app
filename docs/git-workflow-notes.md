# Git Workflow Notes

## Basic Git Workflow

- git status — Check the current repository status.
- git add — Stage changes.
- git commit — Save staged changes to the local repository.
- git push — Send commits to the remote repository.

## Source of Truth

The Git repository is the team source of truth.
The Salesforce org is not the source of truth because changes made directly in the org may not be tracked or reviewed through version control.
